## **What is Robustness Scans?**

This repository demonstrates how to test your Q&A application for common LLM vulnerabilities. Want to know if your app tends to hallucinate? Or whether it may be easily convinced of the opposite of what it reads? Jailbreaks? You can scan for these issues.

### **Key Features:**
- **Hallucination Detection**: Test if your LLM generates false information
- **Adversarial Testing**: Probe for jailbreak vulnerabilities
- **Robustness Assessment**: Evaluate how well your app handles edge cases
- **Easy Integration**: Works with Langchain-based applications
- **Comprehensive Reporting**: Generate detailed vulnerability reports

### **What You'll Learn:**
- How to set up a sample Q&A chatbot using Langchain
- Techniques for probing LLM vulnerabilities using Giskard
- Best practices for securing AI applications
- How to interpret and act on scan results

## **Why Vulnerability Scanning?**

As AI applications become more prevalent, ensuring their security and robustness is crucial. This toolkit provides developers with the tools and knowledge needed to identify and address common LLM vulnerabilities before they become security risks.
